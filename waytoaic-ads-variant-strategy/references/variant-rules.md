# Variant Rules

## Natural position rule

- Each child ASIN has its own keyword weight.
- A parent normally occupies one organic position for a keyword.
- Amazon tends to show the child with the strongest weight or rank for that keyword.

## Ad position rule

- Each child ASIN can have its own ad eligibility and ad delivery.
- Variations under the same parent may not freely occupy the same ad section together.
- Running every child against the same word can split data and spend.

## Why variants matter

Variants can:

- improve CVR
- raise ASP or profit
- cover more attribute-specific traffic
- occupy more paid paths
- support a main ranking SKU

But variants can also:

- split orders away from the main child
- weaken keyword weight concentration
- double ad spend without winning more useful positions

## Role design

Default Soju-style allocation:

- main variation carries about 80% of neutral core traffic
- secondary variations carry the remaining 20% or attribute-specific traffic
- main variation is often slightly lower priced
- secondary variations can support higher price, niche attribute, or paid occupation

## Selecting main SKU

Prefer the child with:

- best conversion chance
- competitive price
- enough review/rating base
- strong offer/coupon if needed
- clear fit with neutral keywords
- healthy inventory

Do not select a high-ASP child as main only because it raises revenue if it weakens keyword weight or CVR.

## Controlled testing

For child ASIN tests:

- same keywords
- same bid logic
- same budget
- same time window
- avoid simultaneous tests when the parent may cannibalize itself
- use fixed bidding when possible

After each test, compare:

- CTR
- CVR
- CPA
- orders
- placement source
- search-term relevance

## Warning signs

- multiple children spend heavily on the same neutral word
- secondary child steals orders but does not improve total parent profit
- all variations use identical campaign structure
- main child has no clear protected keywords
- ad cost doubled but natural position does not improve
